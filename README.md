
# 💻 Laptop Price Prediction

## 📌 Project Overview

This project predicts the price of a laptop based on its specifications using Machine Learning.

## 🎯 Objective

To build a Machine Learning model that can estimate laptop prices based on hardware and system specifications.

## 📊 Features Used

- Brand
- RAM
- Storage
- Processor
- GPU
- Screen Size
- Operating System
- Weight

## 🎯 Target Variable

**Price**

## 🤖 Machine Learning Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## 🏆 Model Selection

All models are compared using:

- R² Score
- MAE
- RMSE

The model with the highest R² Score is selected as the best model.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib
- Streamlit

### Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn joblib streamlit
```

### Run the Streamlit Application

```bash
streamlit run app.py
```

The application accepts laptop specifications and predicts the estimated laptop price.
